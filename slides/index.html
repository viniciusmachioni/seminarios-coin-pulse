React em uma frase

A tela é uma função dos dados. Você muda os dados; o React redesenha a tela.

// JavaScript puro: você mexe na tela
const el = document.querySelector('#total')
el.textContent = formatar(total)
el.classList.toggle('prejuizo', total < 0)
// ...e lembra de fazer isso em
// todo lugar que o total aparece

Imperativo: como mudar a tela, passo a passo.

// React: você descreve a tela
function Total({ total }) {
  return (
    <p className={total < 0 ? 'down' : 'up'}>
      {formatar(total)}
    </p>
  )
}

Declarativo: como a tela deve ser para cada valor.

JSX: HTML dentro do JavaScript

const moedas = ['BTC', 'ETH', 'SOL']

return (
  <ul className="lista">
    {moedas.map((m) => (
      <li key={m}>{m}</li>
    ))}
  </ul>
)
  • { } abre JavaScript dentro do HTML: variáveis, contas, map
  • className no lugar de class porque class já é palavra do JavaScript
  • key em toda lista para o React saber qual item mudou
  • Um elemento pai só ou um fragmento: <>...</>

Componentes e props

O app é um quebra-cabeça de funções. Cada peça recebe dados pelas props.

<Header />
<PortfolioSummary />
<PriceChart />
<PurchaseTable />
<MarketList />
<AddPurchaseForm />
<DollarCompare />
// Quem usa passa a prop...
<Change percent={variacao} />

// ...e o componente recebe
function Change({ percent }) {
  return <span>{percent}%</span>
}

Props descem de pai para filho, e o filho não pode alterá-las.

Estado: o que muda na tela

const [compras, setCompras] = useState([])

function adicionar(compra) {
  // nunca: compras.push(compra)
  setCompras([...compras, compra])
}

useState devolve duas coisas: o valor atual e a função que troca o valor.

Chamou o set? O React redesenha esse componente e os filhos dele, e só altera na tela o que mudou.

Por isso criamos um array novo em vez de usar push: o React compara o antigo com o novo para saber se algo mudou.

Efeitos: falar com o mundo lá fora

useEffect(() => {
  const socket = new WebSocket(url)
  socket.onmessage = (e) => setPrecos(...)

  return () => socket.close()  // cleanup
}, [url])  // roda de novo se url mudar

Tudo que não é desenhar a tela vai num efeito: API, WebSocket, localStorage, timers.

O cleanup desfaz o que o efeito fez. Sem ele, cada vez que o componente monta abre uma conexão nova, e elas se acumulam.

A lista no final diz quando o efeito roda de novo.

Hooks: funções que começam com use

Do React

  • useState guardar o que muda
  • useEffect sincronizar com o mundo de fora
  • useRef guardar algo sem redesenhar

Nossos, criados durante a semana

  • useLocalStorage estado que sobrevive ao F5
  • useLivePrices preços pelo WebSocket
  • useCandles histórico do gráfico

Regra: chame hooks sempre no topo do componente, nunca dentro de if ou de loops.

Rotas: uma URL, uma tela
